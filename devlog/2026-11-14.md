# Dev log: Sat 14 Nov 2026 (jam day 3)

Fable usage ran out, so work continues on Claude Opus 5.5.

## Guards facing backwards
I played the build and the guards were facing the wrong way but still catching ACE. The agent had played every scene
through screenshots and logs without spotting it; from the game camera a figurine's face is a few pixels wide.

The game logic was fine: the watchman was looking at ACE. The models were the problem. Every Meshy figurine stood back
to front because one constant, `FigureYaw`, was +90 instead of -90.

To confirm it, the agent took high-resolution screenshots (`HighResShot 2`) of four scenes, cropped each figure and
compared it with the facing in the level file (watchman south, ACE east). The badge on the watchman's cap pointed north
and ACE faced west, so both were reversed. After the fix, faces, walking direction and sight tiles all line up.

![Before and after: the watchman's face now points along his sight line](img/15-guard-facing-fix.png)

## AI in the loop (Glass Box)
- Me: played the game and described the bug in one sentence.
- Agent: worked out it was the models, not the logic (sight and model rotation use the same direction table), checked
  it with screenshots, fixed it, rebuilt and packaged.
- Takeaway: the automated checks showed the rules worked, but it took someone playing to see that it looked wrong.
