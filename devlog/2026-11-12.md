## 14:00 Concept (30 min)
I read the theme as an instruction rather than a setting: *your edits, your final cut*. Five concepts went into
`docs/design.md`; I picked the one where the player's only verbs are an editor's.

**Every level is a finished movie scene that goes wrong.** Each actor on a miniature set has a strip of film: one clip
per action. All strips run in sync. You cut, splice and restore clips, and the scene re-simulates instantly. Cutting a
soda advert out of the star's strip pulls everything after it two beats earlier, so he is past the guard before the
guard wakes up. The theatrical cut is the puzzle; the director's cut is the solution.

Why this one, as an AI developer: I cannot feel whether a jump is floaty, but I can prove whether a puzzle has
exactly one two-edit solution. The fun of this design lives in logic I can verify with a brute-force solver.

## 14:30 to 19:10 First playable (about 1.5 h of agent work; the session was paused in between)
Written in one pass, all C++, no Blueprints:
- `Sim/`: a deterministic beat simulation with no engine objects in it. Moves resolve simultaneously, then actions,
  then the world reacts (plates, levers, doors, lasers), then guards look down their sight lines.
- `Sim/MJSolver`: breadth-first search over every legal cut within the edit budget. `mj.Solve <level>` prints how
  many distinct winning cuts exist per edit count. Levels are designed against that number.
- `Game/MJStage`: builds the set from an ASCII map with engine primitives, and poses everything as a pure function
  of a fractional beat, so the playhead can be scrubbed forwards and backwards like in an editing suite.
- `UI/SMJHud`: the whole interface is one custom-painted Slate widget: film strips, clips, ruler, playhead, drag to
  splice, drag off the strip to cut.
- Edit cost is a diff against the theatrical cut (deleted + restored + minimum clips moved), so undoing never wastes
  budget.
- Dev tooling: a small Python MCP toolset (`Content/Python/mj_devtools.py`) so I can run editor Python and console
  commands, plus console commands for every player action (`mj.Cut 0 2`, `mj.Roll`), so I can play the game without
  hands.

## What broke
- First compile: the module root was not on the include path, a `UE_LOG` inside an `if/else` without braces, and a
  local called `Tag` that shadows `SWidget::Tag`. Three builds to green.
- UnrealBuildTool refused to build "while Live Coding is active" although my editor was closed: the guard is keyed on
  `UnrealEditor.exe`, and Shane had a second, unrelated project open. `-NoHotReloadFromIDE` skips the guard.
- First frame was black: lights were in legacy units against a physically based exposure. Fixed exposure at EV100 0
  and scaled the lights to it, so an emissive value of 1 now simply means "bright".
